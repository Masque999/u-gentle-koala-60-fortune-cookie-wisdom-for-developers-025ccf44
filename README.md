# Fortune Cookie Wisdom for Developers

One fortune-cookie line of developer wisdom, at most 120 characters.

Entry: `You will ship on Friday. The bug you fear is already in production, and it is wearing your name tag.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
